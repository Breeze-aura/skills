# Stage 3：大纲与用户撰写窗口

选择与课程题型对应的模板，给每一节分配字数。配额相加应等于目标篇幅；
不明确时说明暂以正文字数计算，参考文献是否计入等待课程要求核实。

- 调研：问题、材料/方法、发现、分析、结论；没做调查时不能编造样本或访谈。
- 评论：对象、背景、证据、评价与边界、结论。
- 驳论：准确重述待驳观点、其合理部分、证据与反驳、替代解释。
- 综述：问题、选择范围、研究路径、比较与分歧、评价与缺口。

大纲每节标明目的、字数、可用来源 ID 和“AI 可辅助 / 用户亲笔”。
用户的中心判断、核心评价、反驳与结论观点必须留在亲笔窗口。
AI 可以整理已核背景和材料摘要，但它们不能偷偷替代关键论证段落。

## 支持包的形状

给每个亲笔窗口列出：

1. 这一段要回答的分析问题。
2. 可用证据的来源 ID 与定位。
3. 用户可以比较的条件、限制或反例。
4. 与上一段、下一段的结构关系。

这些都是问题和索引，不是写好的论点句、待填空正文或可直接提交的示范段落。
先让用户确认大纲；确认后可分段收取亲笔稿，降低一次写完的负担。
未收到原稿就记录“等待用户撰写”，不能把 AI 生成段落写进原稿栏。

**Gate 3**：大纲得到确认且必要亲笔段落已提供后，进入 Stage 4。
反馈与补问仍属于 Stage 3；可给原稿单列建议，但不会在组装中擅自替换。
