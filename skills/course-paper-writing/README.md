# course-paper-writing

状态：**0.4.1-draft**。根据交接设计新建的首个工程；原始 v0.3 文件尚未迁入，
此版本不宣称是其完整恢复，也不宣称已完成真实课程论文验证。

面向 2000–5000 字课程小论文：调研、评论、驳论、综述。输入只需“选题 + 要求”。
四阶段由用户逐次确认：立意 → 资料 → 大纲与亲笔窗口 → 组装与反馈。

```text
$course-paper-writing
课程：新中国史
题型与篇幅：评论，2000字
选题：深圳经济特区与邓小平同志
其他要求：体现自己的判断
```

已有进展时附上项目状态或已确认立意，skill 从未完成阶段继续。
原稿与状态属于具体课程项目，不存到已安装的 skill 文件夹。

AI 给分析问题、证据与结构；关键判断由用户亲笔完成，组装保留用户原文。
事实、数据与引文要回查来源；没有核实的内容不会进入可提交版本。
本工具不承诺 AI 检测分数，也不替代课程规定。

入口见 [SKILL.md](SKILL.md)，模拟首次使用见
[examples/stage-1-demo.md](examples/stage-1-demo.md)。
文献检索可直接使用浏览与用户提供的文献，也可调用可选的 `paper-search`。
检索结果按来源 ID 接入资料包，保留阅读状态，全文回查与 Gate 2 仍由写作流程负责。

安装与仓库验证方式见
[仓库 README](https://github.com/Breeze-aura/skills#readme)。
