## 主题 / 论证用途

### S01：题名

**出处与版本：**作者、年份、刊物、卷期页码、真实入口、实际文件/版本。
**来源类型：**学术研究 / 理论文章 / 讲话 / 法规 / 统计 / 报道 / 其他。
**阅读范围：**仅题录 / 仅摘要 / 部分正文 / 全文已取得未读完 / 全文已通读 / 缺全文。
**具体范围与记录归属：**已读页段、相关表图/附录/脚注，未覆盖内容；本人本轮阅读或继承谁的记录。

**独立阅读摘要（未通读则改为部分阅读笔记或摘要层次线索）：**
研究问题 → 材料/方法 → 主要论证过程 → 结论 → 条件与重要限制。
