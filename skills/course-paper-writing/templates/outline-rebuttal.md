| 节 | 任务 | 字数 | 来源 ID | 写作责任 |
| --- | --- | ---: | --- | --- |
| 问题 | 待驳观点与争议范围 | 200 | | 用户选定目标与立场 |
| 重述 | 准确重述对方观点与合理部分 | 400 | | AI 可依原文整理 |
| 证据 | 检验该观点的依据 | 500 | | AI 可核实材料 |

| 合计 | | 2000 | | |
