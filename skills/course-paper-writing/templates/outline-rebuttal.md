# 驳论类大纲

以下仅演示 2000 字章节预算，实际配额按课程上限与计数范围调整。
摘要、关键词、标题等需要计入时先预留其预算，再分配章节；不能默认为“正文 2000 字另加摘要”。

| 节 | 任务 | 示例配额 | 来源/主张 ID | 用户观点或材料依据 |
| --- | --- | ---: | --- | --- |
| 问题 | 待驳观点与争议范围 | 200 | | 用户选定目标与立场 ID |
| 重述 | 准确重述对方观点与合理部分 | 400 | | 有原始出处 |
| 证据 | 检验该观点的依据 | 500 | | 已核材料 |
| 反驳 | 推理问题、边界与替代解释 | 700 | | 用户确认的核心反驳 ID |
| 结论 | 限定后的判断 | 200 | | 用户确认的结论 ID |
| 合计 | | 2000 | | |

重述必须准确、有原始出处，不构造稻草人；分析同时保留对方的合理部分。
关键判断可通过讨论回答采集，不强制写成四段亲笔稿；AI 新稿按确认内容组织。
真实原稿另行保留并遵守修改范围，不把讨论样本或 AI 概括冒充亲笔成稿。
Gate 3：return 自检后确认结构、观点及最后格式，再由网页端直接生成论文并更新 return。
