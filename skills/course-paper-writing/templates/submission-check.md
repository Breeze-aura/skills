- 网页论文 / 最新 return / 阅读摘要 / 教师原始通知的文件与版本：
- 已采用的确认记录、协作方式与校准范围：
- 当前结果：待核工作稿 / 待用户决定 / 校准后候选提交版 / 用户已认可。

## return 与实际论文对照

- 已确认观点、结构、表达偏好是否落实：
- 教师原文、用户追加、AI 建议与最终格式方案是否一致：
- 论文版本或新增来源与 return 是否一致；实际差异及处理：

## 原话、原稿与改动

- 用户原话/样本档案、真实原稿入口及保存情况：
- AI 辅助新稿与真实原稿区分、已授权改动范围：

## 篇幅与实际格式

- 教师原始上限与豁免范围、用户追加内容：
- 统计方式：中文 / 英文 / 数字 / 标点 / 注释，Word 统计或自定义方法及其限度。
- 正文计数、摘要/关键词计数、其他计入项、按有效要求的合计：
- 字体字号、行距、标题/章节、实际文件类型：
- 引注与来源对应；需页下注时原生页下注检查结果（Markdown 定义不算）：
- 文后参考文献是否按实际要求保留或省略：
- 文档结构检查、渲染工具、逐页预览入口与结果；未完成项：
- 草稿工作标记是否移出候选提交版、课程 AI 要求是否满足：
