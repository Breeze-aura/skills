# 评论类大纲

以下为 2000 字正文示例配额。按实际目标等比例调整，并检查合计。

| 节 | 任务 | 字数 | 来源 ID | 写作责任 |
| --- | --- | ---: | --- | --- |
| 引言 | 对象与评价问题 | 200 | | AI 可辅助背景；中心判断由用户写 |
| 背景 | 解释评论对象的条件 | 400 | | AI 可整理已核资料 |
| 证据 | 相关事实与不同解释 | 500 | | AI 整理；推理归属明确 |
| 评价与边界 | 用户评价、理由与限制 | 700 | | 核心判断段用户亲笔 |
| 结论 | 回答评价问题 | 200 | | 结论观点用户亲笔 |
| 合计 | | 2000 | | |

每个亲笔窗口附分析问题、证据索引、限制与结构关系；不附可提交示范段落。
Gate 3：确认大纲，再收齐必要亲笔段落。
