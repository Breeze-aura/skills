# 综述类大纲

以下为 2000 字正文示例配额。按实际目标等比例调整，并检查合计。

| 节 | 任务 | 字数 | 来源 ID | 写作责任 |
| --- | --- | ---: | --- | --- |
| 问题 | 研究主题与综述范围 | 200 | | 用户确认评价问题 |
| 选材 | 文献选择范围与检索方式 | 200 | | 如实记录实际做法 |
| 研究路径 | 按问题或观点组织已有研究 | 900 | | AI 可依读到的原文整理 |
| 比较 | 共识、分歧、证据限制与缺口 | 500 | | 核心比较和评价用户亲笔 |
| 结论 | 本次综述的限定判断 | 200 | | 结论观点用户亲笔 |
| 合计 | | 2000 | | |

不把逐篇摘要拼接当作综述。普通课程综述不能伪称采用了未执行的系统综述方法。
亲笔窗口只附问题和索引。Gate 3：确认大纲，再收齐必要亲笔段落。
