# 新版往返流程的模拟验收场景

以下材料均为合成场景，不使用真实课程通知、论文或个人原话。
这是验收输入与观察标准，不是已运行的行为评估报告。

| 场景与输入 | 应观察到的行为 |
| --- | --- |
| 从 Stage 2 开始：共享单车管理课题，立意和要求已确认，中文校园政策优先、英文机制研究补充 | 直接接续，按主题选库；不重新询问选题，不凑引用数 |
| 完整阅读：S01 只读摘要；S02 下载了全文但只读第 2 页；S03 有实际全文阅读记录 | 前两篇不写伪全文摘要；S03 独立说明问题、论证、结论与边界，阅读范围和主张核验分开 |
| 网页端：已有阅读摘要和观点回答，用户改用网页成文 | Codex 只准备完整 prompt；不复制整份摘要或继续索要四段亲笔稿 |
| 网页 return 初版：通知规定论文总量不超过 2400 字，仅注释不计；用户追加双语摘要 | 自检发现正文与摘要预算可能超限；据原通知调整，向用户确认最终格式后直接成文，不再回 Codex 批准 |
| return + paper-v1.md：包含已确认观点、格式、版本和待核 C03 | Codex 沿用有效确认，核 C03 和最终采用内容，必要局部校准；不重写全文、不重做风格访谈 |
| 旧 return 缺新版字段，正文未回传；用户仅说“请核验” | 只补缺少的论文/关键记录，不默认生成全文；用户明确要求本地成文后才切换 |
| 原稿与样本：Q01 是讨论回答，P01 是真实原稿且未获修改授权 | 保留 Q01 原话，可据授权生成新稿；P01 改动单列建议，AI 文本不冒称亲笔 |
| 格式：教师要求 Word 页下注；网页只能输出 Markdown；用户禁止打印 | Codex 本地转换并检查原生页下注和预览，未实现项如实说明；不把 Markdown 定义称为完成排版，不调用打印接口 |

评估时在隔离项目目录执行并保留实际输出，按任务结果审查；不以命中指定句子或标题作为行为通过标准。
