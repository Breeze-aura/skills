# 数据源范围与运行约定

## 先按主题选库

先判断研究对象与语料语言、所属学科、所需文献类型和当前可访问资源，
确定优先检索的库及理由，再安排查询。库的选择适用于检索、阅读和资料整理，
不由某个脚本的数据源决定。

| 主题与资料需求 | 优先来源 | 补充与整理 |
| --- | --- | --- |
| 中文语料、中国历史或中文文化主题 | 中文文献库、中文学术期刊与相关教材；史实和政策回到原始资料 | 先用中文词检索，再按问题补充外文研究；记录语境和版本 |
| 学科科研问题，如 EEG、脑机接口 | 该学科专业文献库、专业期刊的原始研究和综述 | 通用学术检索用于发现线索，预印本作为补充并标明出版状态 |
| 政策、历史资料或正式数据 | 与对象相关的官方原始文献、档案、教材或正式统计来源 | 学术研究用于解释；不能用不相关的预印本替代原始证据 |

语言与来源都按问题需要匹配，中文主题优先中文文献不等于排除外文研究。
记录所选文献库、选择理由、检索语言、实际检索式与筛选范围。
无访问条件时说明限制，使用可访问版本或用户提供的文献，不暗示读过付费全文。

当前脚本只连接 Semantic Scholar 与 arXiv。其他专业或中文文献库由浏览和
用户可访问资源支持，不新增未经实现的 API、自动抓取或全文下载承诺。

## Semantic Scholar

采用 Academic Graph 的相关度检索端点 `/graph/v1/paper/search`，单次候选数量
控制在 1–100。`--sort citations` 是脚本对这些候选的重新排序，不保证全库最高被引。
请求不执行分页、引文网络扩展或系统综述的完整检索。

匿名访问共享限流额度，提供 key 也不意味着不会限流。脚本支持环境变量
`SEMANTIC_SCHOLAR_API_KEY`，不负责申请 key、修改全局凭据或安装新连接器。
429、5xx 与网络错误有界重试；其他 HTTP 错误不反复重试。

官方来源：[API 文档](https://api.semanticscholar.org/api-docs/)、
[API 教程](https://www.semanticscholar.org/product/api/tutorial)。

## arXiv

采用 HTTPS API，默认按相关度返回候选。`published` 表示首版提交日期，
`submittedDate` 是提交日期检索范围，不是期刊发表日期。
错误也可能包装成 Atom feed；脚本检查错误条目，不把它当论文。
连续调用至少间隔 3 秒，避免并发。被引数保持未知。

arXiv 的学科覆盖与正式出版文献不同；“服务可用”不意味着对当前问题有足够资料。
无相关资料时说明覆盖空缺，换检索词或手工补充适合该学科的数据源。

官方来源：[arXiv API User's Manual](https://info.arxiv.org/help/api/user-manual.html)。

## 元数据与原文

脚本只能返回检索元数据和摘要。数据源、检索时间和年份口径可以回查，
但正文证据、具体数据、引文与页码仍要在后续精读中核实。
没有摘要时不生成研究结论；没有全文时不标“正文已核”。
