# 论文检索整理

## 什么时候用
当用户想找某个主题的论文、了解一个方向的代表性工作、整理待读清单、或为课程/科研论文找参考文献时，用这个 skill。不要在用户只是闲聊提到某篇论文时触发。

## 怎么用
1. **问清需求**：主题关键词（英文关键词效果更好，可帮用户把中文翻译成英文）、要几篇（默认 8 篇）、是否优先综述（review）。
2. **跑检索脚本**：
   ```
   python3 scripts/search_papers.py --query "english keywords" --limit 8
   ```
   可选参数：`--sort citations` 按被引数排序（找代表性工作时用）；`--year-from 2020` 只看近年的。
3. **整理输出**：每篇给出标题 / 作者（前三 + et al.）/ 年份 / 期刊或会议 / 被引数 / 一句话中文简介 / 链接。简介用自己的话写，不要复制摘要。
4. **存清单**：如果用户说"存下来/记下来"，用 `--save` 参数追加到 `reading_list.md`，按主题分组。不要重复收录已有的条目（用标题去重）。

## 数据来源
- Semantic Scholar API（免 key，低频使用）：提供标题、摘要、被引数、发表 venue、链接。注意控制请求频率；遇到 429 限流脚本会自动重试。
- arXiv API（自动兜底）：Semantic Scholar 不可用时自动切换，保证不断连；缺点是没有被引数和期刊信息。
- **铁律**：所有论文信息必须来自 API 返回，绝不编造标题、作者或链接。API 没返回的就是没有。

## 输出格式示例
```
1. 《标题》
   作者（年份）· 期刊/会议 · 被引 N · [链接](url)
   一句话：中文简介，为什么值得读。
```

## 待读清单
见 `reading_list.md`，按主题分组记录已收藏的论文。
