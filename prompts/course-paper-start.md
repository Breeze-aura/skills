# 开始或继续一篇课程小论文

复制提示词，填写已有信息；其余只在需要时补充。

```text
使用 $course-paper-writing 帮我推进课程小论文。

课程、题型、选题或主题范围：
教师原始通知（含篇幅、计数范围、引注与格式）：
我的追加要求（如重点、文献语言、表达偏好）：
其他要求（截止日、课程AI规定等）：

如果已有进展：
已确认立意与最新约定：
当前阶段、阅读摘要、return、论文或原稿：

从未完成的任务继续，已有观点与材料不重复采集。
默认由Codex准备资料和网页prompt，网页端生成return、自检、
向我确认最后格式后直接生成论文，再将论文和最新return交Codex核验校准。
我的观点可以通过讨论采集，不强制先写四段亲笔稿；保留真正原稿并遵守修改授权。
事实和引文回查来源，教师原文、我的追加与AI建议分开，阶段确认不重复进行。
```

未安装 skill 时，可连同对应 `SKILL.md` 提供给助手；
网页交互的专用模板见 [web-llm-prompt.md](../skills/course-paper-writing/templates/web-llm-prompt.md)。
